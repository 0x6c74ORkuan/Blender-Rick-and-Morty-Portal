### 首先推荐blender版本使用4.5，用5.0可能会导致渲染的时候闪退（up主遇到好多次）

需要准备：独立显卡；一个可以被追踪点标记的视频；blender软件；github

1. 打开blender主界面点击上方加号选择VFX➡️运动追踪  
![图片说明](./Pasted%20image%2020260805153901.png)

2. 打开拍好的视频照着图中顺序设置（顺序4是要设置同样的帧数，包括浮点）  
![图片说明](./Pasted%20image%2020260805154943.png)

3. “ctrl+左键”打上标记，按"A"全选然后"S"放大一下，再点击下方的向前追踪标记  
![图片说明](./Pasted%20image%2020260805155106.png)

4. 下面出现波形图和按空格播放观看，没有标记点丢失就可以下一步了  
![图片说明](./Pasted%20image%2020260805155404.png)

5. 点击摄像机运动解算，然后看解算错误多少（解算错误1.0往下就不用看第6项）  
![图片说明](./Pasted%20image%2020260805155652.png)

6. 在顶部编辑➡️偏好设置获取扩展，搜索"Refine tracking solution"，再第三步点击Refine，一般情况解算错误会到0.0几  
![图片说明](./Pasted%20image%2020260805155909.png)

7. 在场景设置的"设为背景图"和"设置追踪场景"点一下（基面是"地面的意思"，立面是"XY的意思"，看你的追踪场景是什么样的）  
![图片说明](./Pasted%20image%2020260805160313.png)

8. 在顶部切换成"布局"界面，再根据第二步把运动追踪打开，第三步把渲染引擎换成"cycles"  
![图片说明](./Pasted%20image%2020260805160746.png)

9. 并且右边栏照这么设置  
![图片说明](./Pasted%20image%2020260805161113.png)

10. 在右上角界面选择"Ground"模型，在右下角渲染往下划找到胶片"透明"选项打开  
![图片说明](./Pasted%20image%2020260805161337.png)

11. 然后上方渲染图像看看和图片中是否一致（有阴影和场景）就说明成功一半了！！  
![图片说明](./Pasted%20image%2020260805161601.png)

12. 在github搜索这个并下载Releases里面的blender格式文件

13. 删除原来的正方体，并且把"Ground"放到和摄像机画面一样大  
![图片说明](./Pasted%20image%2020260805164524.png)

14. 在上方追加github下载的Releases文件，然后在新的弹窗选择"Object"并导入进来  
![图片说明](./Pasted%20image%2020260805165538.png)

15. 接着在右上角找到"Portal"并点击，然后在右下角材质属性往下翻找到透明阴影就完成了！！！  
![图片说明](./Pasted%20image%2020260805172713.png)

16. 最后一步也就是调整传送门的缩放位置了  
![图片说明](./Pasted%20image%2020260805172816.png)

17. 然后输出面板设置帧率，接着渲染视频就大功告成！
